## Blockchains
- [Aleo](https://github.com/AleoNet/snarkOS).
  Sistema operativo descentralizado para aplicaciones zero-knowledge.
- [Aleph Zero](https://github.com/aleph-zero-foundation).
  DAG, PoS, contratos inteligentes snark (basado en substrate).
- [Anoma.network](https://github.com/anoma).
  Blockchain PoS con privacidad.
- [Aptos Network](https://github.com/aptos-labs).
  Construyendo la blockchain Layer 1 más segura y escalable.
- [Bitcoin Cash](https://github.com/be-cash/bitcoin-cash).
  Una librería para crear y parsear transacciones de Bitcoin Cash.
- [Casper](https://github.com/casper-network/casper-node).
  Una blockchain L1 PoS descentralizada diseñada para acelerar la adopción empresarial y de desarrolladores.
- [Chainflip](https://github.com/chainflip-io/chainflip-backend/).
  Swaps Cross-Chain Nativos.
- [CITA](https://github.com/cryptape/cita).
  Un kernel de blockchain de alto rendimiento para usuarios empresariales.
- [CodeChain](https://github.com/CodeChain-io/codechain).
  Cadena multi-activo programable.
- [Concordium](https://github.com/Concordium).
  Cadena PoS centrada en privacidad (zk), con identidades integradas y contratos inteligentes en rust.
- [Conflux](https://github.com/Conflux-Chain/conflux-rust).
  La implementación en Rust del protocolo Conflux.
- [Darwinia](https://github.com/darwinia-network/darwinia).
  Cadena de relevo de Darwinia Network, puede conectarse a Polkadot como parachain en el Modelo Polkadot.
- [Dusk.network](https://github.com/dusk-network).
  PoS de privacidad usando zk (plonk).
- [Enigma](https://github.com/enigmampc/enigma-core) asegura la web descentralizada.
- [Ethrex](https://github.com/lambdaclass/ethrex).
  Implementación minimalista y rápida del protocolo Ethereum en Rust. Cliente de ejecución L1 y L2.
- [MultiversX](https://github.com/multiversx).
  Plataforma de ejecución de Contratos Inteligentes fragmentada con mecanismo de consenso PoS.
- [Exonum](https://github.com/exonum/exonum).
  Un framework extensible de código abierto para crear aplicaciones de blockchain privadas/permisionadas.
- [Forest](https://github.com/ChainSafe/forest).
  Una implementación de Filecoin escrita en Rust.
- [Fuel](https://github.com/FuelLabs/fuel-core).
  Implementación de nodo completo en Rust del protocolo Fuel.
- [Gear](https://github.com/gear-tech/gear).
  Componente computacional de la red Polkadot.
- [Grin](https://github.com/mimblewimble/grin).
  Implementación minimalista del protocolo MimbleWimble.
- [Holochain](https://github.com/holochain/holochain).
  El framework central Holochain escrito en rust, un contenedor, y librería hdk-rust para escribir Zomes.
- [Interledger](https://github.com/interledger-rs/interledger-rs).
  Una implementación de Interledger fácil de usar y de alto rendimiento escrita en Rust.
- [Internet Computer Protocol (ICP)](https://github.com/dfinity/ic).
  La primera blockchain del mundo que funciona a velocidad web y puede aumentar su capacidad sin límites.
- [Internet of People](https://github.com/Internet-of-People/iop-rs).
  Stack de software descentralizado que proporciona los bloques de construcción y herramientas para apoyar una sociedad descentralizada.
- [Libra](https://github.com/libra/libra).
  Moneda global e infraestructura financiera que empodera a miles de millones de personas.
- [Lighthouse](https://github.com/sigp/lighthouse).
  Cliente de Ethereum 2.0 rápido y seguro.
- [Namada](https://github.com/anoma/namada).
  L1 Proof-of-Stake para privacidad interchain agnóstica de activos.
- [NEAR](https://github.com/nearprotocol/nearcore).
  NEAR Protocol - blockchain escalable y usable.
- [Nervos CKB](https://github.com/nervosnetwork/ckb).
  Nervos CKB es una blockchain pública sin permisos, la capa de conocimiento común de la red Nervos.
- [NYM](https://github.com/nymtech/nym).
  Privacidad selectiva vía mixnet previniendo análisis de metadatos.
- [Nomic](https://github.com/nomic-io/nomic).
  Nomic es una sidechain de Bitcoin de alto rendimiento que es parte de la red Cosmos.
- [Mina Protocol](https://github.com/ChainSafe/mina-rs).
  Una implementación en rust de la blockchain sucinta de mina.
- [Mir Protocol](https://github.com/mir-protocol).
  Una blockchain sucinta impulsada por pruebas zero-knowledge. (basada en plonk)
- [OpenEthereum](https://github.com/openethereum/openethereum).
  El cliente Ethereum en Rust
- [Parity Bitcoin](https://github.com/paritytech/parity-bitcoin).
  El cliente Parity Bitcoin.
- [Parity Ethereum](https://github.com/paritytech/parity-ethereum).
